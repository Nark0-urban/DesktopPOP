# DesktopPop

바탕화면 아이콘을 숨겨 두고, **마우스를 화면 왼쪽/오른쪽 끝에 대면 아이콘이 튀어나오게** 하는 Windows 프로그램이에요.
선택·실행·우클릭 메뉴·끌어서 옮기기는 원래 바탕화면과 똑같고, 아이콘을 보관하는 **"가방"** 이 추가돼요.

## 받아서 쓰기

1. 오른쪽 **Releases** 에서 `DesktopPop-x.x.x-win-x64.zip` 을 받아요.
2. 원하는 폴더에 압축을 풀어요.
3. `DesktopPop.exe` 를 더블클릭 (따로 설치할 건 없어요)

"알 수 없는 게시자" 경고가 뜨면 **추가 정보 → 실행** 을 누르세요.

## 원래 바탕화면과 다른 점

- 아이콘은 화면 왼쪽/오른쪽 끝에 마우스를 대야 보여요 (처음 켤 때 원래 왼쪽/오른쪽 배치대로 나뉨)
- 아이콘 위치는 가장자리 판 안에서만 바꿀 수 있어요
- 바탕화면에 파일 넣기: 탐색기에서 화면 끝으로 끌고 가 판에 놓기, 또는 판 빈 곳 우클릭 → 새 폴더 / 붙여넣기
- 게임·영상 전체화면이나 최대화된 창이 앞에 있으면 안 튀어나와요

## 추가된 기능

- **가방:** 아이콘을 끌어 넣어 보관하고, 클릭하면 주변으로 펼쳐져요 (파일은 실제로 옮겨지지 않음)
- **새 파일 알림:** 바탕화면에 새 파일이 생기면 그쪽 가장자리가 열리며 반짝여요
- **설정:** 색상, 튀어나오는 속도, 윈도우 켤 때 자동 실행 등 (시계 옆 아이콘 메뉴)

설정과 가방은 `DesktopPop.exe` 옆 `data` 폴더에 저장돼요.

## 지우는 법

1. 시계 옆 DesktopPop 아이콘 우클릭 → **"윈도우 켤 때 자동 실행"** 체크를 꺼요 (켜 두었던 경우만)
2. 같은 메뉴에서 **"종료"** → 원래 바탕화면 아이콘이 다시 보여요
3. 압축 푼 폴더를 통째로 지우면 끝 (폴더 밖에는 아무것도 안 남아요)

바탕화면 아이콘이 안 돌아오면: 바탕화면 우클릭 → 보기 → **"바탕 화면 아이콘 표시"** 체크.

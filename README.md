# DesktopPop

바탕화면 아이콘을 숨겨 두고, **마우스를 화면 왼쪽/오른쪽 끝에 대면 아이콘이 튀어나오게** 하는 Windows 프로그램이에요.
선택·실행·우클릭 메뉴·끌어서 옮기기는 원래 바탕화면과 똑같고, 아이콘을 보관하는 **"가방"** 이 추가돼요.

## 받아서 쓰기

1. 오른쪽 **Releases** 에서 `DesktopPop-x.x.x-win-x64.zip` 을 받아요.
2. 원하는 폴더에 압축을 풀어요.
3. `DesktopPop.exe` 를 더블클릭 (따로 설치할 건 없어요)

"알 수 없는 게시자" 경고가 뜨면 **추가 정보 → 실행** 을 누르세요.

## 원래 바탕화면과 다른 점

- 아이콘은 화면 왼쪽/오른쪽 끝에 마우스를 대야 보여요 (처음 켤 때 원래 왼쪽/오른쪽 배치대로 나뉨)
- 아이콘 위치는 가장자리 판 안에서만 바꿀 수 있어요
- 바탕화면에 파일 넣기: 탐색기에서 화면 끝으로 끌고 가 판에 놓기, 또는 판 빈 곳 우클릭 → 새 폴더 / 붙여넣기
- 그 가장자리에 실제 바탕화면이 보일 때만 자동으로 튀어나와요 (프로그램 창 위에서는 '패널 열기' 버튼 사용)
- 우클릭 메뉴는 앱 자체 메뉴예요. 압축·공유 같은 Windows 확장 메뉴는 "탐색기에서 추가 메뉴..."로 열어요

## 추가된 기능

- **모니터별 패널:** 모니터마다 왼쪽/오른쪽 패널이 따로 있어요 (듀얼 모니터면 4개)
- **패널 열기 버튼:** 떠 있는 버튼으로 모든 패널과 가방을 다른 프로그램 위로 펼쳐요
- **단축키 `Ctrl+Alt+D`:** 어디서든 눌러서 모두 펼치기, 한 번 더 누르면 접기 (트레이 메뉴에서 원하는 키 조합으로 직접 정하거나 끌 수 있음)
- **가방:** 아이콘을 끌어 넣어 보관하고, 클릭하면 주변으로 펼쳐져요 (파일은 실제로 옮겨지지 않음)
- **새 파일 알림:** 바탕화면에 새 파일이 생기면 그쪽 가장자리가 열리며 반짝여요
- **복구 감시:** 프로그램이 비정상 종료돼도 원래 바탕화면 아이콘을 다시 보이게 해요
- **설정:** 색상, 튀어나오는 속도, 윈도우 켤 때 자동 실행 등 (시계 옆 아이콘 메뉴)

설정과 가방은 `DesktopPop.exe` 옆 `data` 폴더에 저장돼요.
그 폴더에 쓸 수 없으면(예: Program Files) `%LOCALAPPDATA%\DesktopPop\data` 를 대신 써요.

## 지우는 법

1. 시계 옆 DesktopPop 아이콘 우클릭 → **"윈도우 켤 때 자동 실행"** 체크를 꺼요 (켜 두었던 경우만)
2. 같은 메뉴에서 **"종료"** → 원래 바탕화면 아이콘이 다시 보여요
3. 압축 푼 폴더를 통째로 지우면 끝 (폴더 밖에는 아무것도 안 남아요)

바탕화면 아이콘이 안 돌아오면: 바탕화면 우클릭 → 보기 → **"바탕 화면 아이콘 표시"** 체크.

## 직접 빌드하기

Windows + [.NET 10 SDK](https://dotnet.microsoft.com/download) 가 있으면:

```powershell
powershell -ExecutionPolicy Bypass -File build-zip.ps1
```

`dist` 폴더에 zip 이 만들어져요.

## 개발 메모

1.1.x 코드는 다른 분이 고친 1.1.3 배포본(exe)을 역컴파일해서 되살린 거예요.
그래서 원래 주석이 거의 없고 지역 변수 이름(`num`, `flag`, `text` 등)이 기계적이에요.
동작은 1.1.3과 같다는 걸 확인했어요 (이름 있는 메서드 763개, 코드 속 문자열 559개 일치).

DesktopPop 사용법
==================

[1.1.4 개선]
  - NVIDIA GeForce 오버레이 같은 투명한 오버레이 창이 있으면 가장자리 패널이
    열렸다 닫혔다를 반복하던 문제를 고쳤어요.
  - 단축키 Ctrl+Alt+D: 어디서든 누르면 모든 패널과 가방이 펼쳐지고, 한 번 더 누르면 접혀요.
    (펼친 뒤 다른 곳을 클릭하거나 다른 프로그램에서 키를 눌러도 접혀요)
    시계 옆 아이콘 → '펼치기/접기 단축키'에서 다른 키로 바꾸거나 끌 수 있어요.
    '직접 정하기...'를 누르고 원하는 키 조합을 누르면 그 키로 정해져요.
    (Ctrl, Alt, Win 중 하나는 같이 눌러야 해요. 다른 프로그램이 쓰는 키면 알려 줘요)
  - 처음 실행할 때 원래 바탕화면 배치를 읽는 방식을 Windows 공식 방식으로 바꿨어요.
    (예전 방식은 백신이 악성 프로그램으로 오해할 수 있었어요)
  - 배치를 읽을 때 이름 대신 실제 경로로 맞춰서, 이름이 같은 아이콘도 제자리를 찾아요.
  - 프로그램 폴더에 쓸 수 없으면(예: Program Files) 설정을 사용자 폴더
    %LOCALAPPDATA%\DesktopPop\data 에 대신 저장해요.
  - DesktopPop 폴더를 옮긴 뒤에도 윈도우 켤 때 자동 실행이 계속 되도록 경로를 고쳐요.

[1.1.3 개선]
  - 전체 열기에 쓰는 아이콘 화면을 미리 준비해 재사용하고, 글자와 그림자 캐시로 애니메이션 부하를 줄여요.
  - 파일이 바뀌면 바뀐 아이콘만 갱신해요. 썸네일을 읽는 동안에도 화면을 계속 사용할 수 있어요.
  - 선택·마우스 이동의 중복 처리를 줄이고, 닫힌 패널·가방의 애니메이션을 정리해요.
  - 보조 모니터의 아이콘 이동 효과도 경로에 필요한 영역만 그려요.
  - 패널을 닫으면 모든 모니터의 가방이 프로그램 창들 뒤, 바탕화면 위로 내려가요.

[1.1.2 개선]
  - 가방을 펼칠 때 예전 원형·부채꼴의 모양을 유지하고, 겹치면 전체 간격만 같은 비율로 넓혀요.
  - 프로그램 위에서 전체 열기 후 닫으면 작업하던 창이 앞으로 돌아오고, 가방은 프로그램 뒤로 내려가요.
  - 다른 앱을 직접 클릭해 닫았다면 그 앱으로 이어서 작업해요. 바탕화면에서 열었을 땐 바탕화면에 남아요.

[1.1.1 개선]
  - 전체 열기 후 바깥을 클릭·스크롤하거나 다른 프로그램에서 작업하면 펼친 패널과 가방 내용이 접혀요.
  - 패널과 가방 안의 선택·드래그·이름 입력은 계속할 수 있고, 아이콘을 실행하면 접혀요.
  - 두 모니터 가운데 경계는 양쪽 16px까지 감지해요. 바탕화면이 보이는 쪽만 열려요.
  - 가방이 보조 모니터로 이동해도 그 모니터의 작업 영역을 기준으로 펼쳐져요.
  - 펼친 아이콘과 가방 이름이 겹치지 않게 배치하고, 모서리에서는 화면 안쪽 자리를 찾아요.
  - 새 가방은 만들기를 누른 모니터에 생겨요. 화면 연결이 바뀌어 가방이 벗어나면 가까운 화면으로 돌아와요.

[1.1.0 새 기능]
  - 모니터마다 좌우 패널을 따로 사용해요. 듀얼 모니터는 총 네 개이며 아이콘과 순서는 독립적이에요.
  - 기존 양쪽 아이콘은 주 모니터에 유지돼요. 보조 모니터의 빈 패널로 끌어 놓거나 우클릭 이동 메뉴로 옮겨요.
  - 자동으로 열리는 조건: 해당 가장자리에 실제 바탕화면이 보일 때만 열려요.
  - 두 화면의 가운데 경계에서는 둘 다 바탕화면이면 두 패널, 한쪽만 바탕화면이면 그쪽 패널만 열려요. 둘 다 프로그램 창이면 열리지 않아요.
  - 떠 있는 '패널 열기' 버튼: 모든 패널과 가방 내용을 다른 프로그램 위로 펼쳐요. 다시 누르거나 다른 작업을 시작하면 접혀요.
  - 버튼을 드래그해서 위치를 바꿔요. 화면 아래 작업 표시줄 위에도 놓을 수 있고 위치가 저장돼요.
  - 버튼을 숨겼다면 시계 옆 메뉴 → '떠 있는 패널 버튼 표시'로 다시 켤 수 있어요.
  - 가방 그림 보관함에 사이버 6종, 건축·수학 스팀펑크 6종이 추가돼요. 기존 그림은 보존돼요.
  - 우클릭은 앱 자체 메뉴를 사용해요. 압축·공유 등 Windows 확장 메뉴는 '탐색기에서 추가 메뉴...'로 열어요.
  - 이름이 같은 폴더·바로가기는 종류와 실제 경로로 구별해요. 마우스를 올리면 전체 경로가 보여요.
  - 비정상 종료 후에도 복구 감시 프로세스가 원래 바탕화면 아이콘을 다시 표시해요.

바탕화면 아이콘을 숨겨 두고, 마우스를 화면 왼쪽/오른쪽 끝에 대면 아이콘이 튀어나오게 해요.
선택, 실행, 복사와 끌어서 옮기기를 지원해요.


[원래 바탕화면과 다른 점]
  - 아이콘은 화면 왼쪽/오른쪽 끝에 마우스를 대야 보여요. 마우스를 떼면 들어가요.
    처음 켤 때 원래 왼쪽에 있던 아이콘은 왼쪽, 오른쪽에 있던 건 오른쪽으로 가요.
  - 아이콘 위치는 가장자리 판 안에서만 바꿀 수 있어요. 빈 바탕화면에 놓으면 취소돼요.
  - 끌어서 여러 개 고르는 네모는 가장자리가 열려 있을 때만 나와요.
  - 바탕화면에 파일을 넣을 때: 탐색기에서 화면 끝으로 끌고 가서 판에 놓거나,
    판의 빈 곳 우클릭 → 새 폴더 / 붙여넣기.
  - 이름 바꾸기는 입력 창에서 해요.
  - 자동 열기는 각 모니터 가장자리에 바탕화면이 보일 때만 작동해요.
    프로그램 위에서 사용하려면 떠 있는 '패널 열기' 버튼을 누르세요.


[추가된 기능]
  가방
    - 만들기: 시계 옆 DesktopPop 아이콘 우클릭 → "새 가방 만들기" → 그림 고르기
    - 아이콘을 가방에 끌어다 놓으면 보관, 가방을 클릭하면 주변으로 펼쳐져요.
    - 펼친 아이콘을 원 밖으로 살짝 끌어 놓으면 꺼내져요 (놓은 쪽 가장자리로 돌아감).
    - 가방 끌기 = 위치 이동, 가방 우클릭 = 이름 / 그림 / 크기 / 지우기
    - 파일을 실제로 옮기는 게 아니라 보여 주는 곳만 바뀌어요.

  새 파일 알림
    - 바탕화면에 새 파일이 생기면 그쪽 가장자리가 열리면서 반짝여요.

  시계 옆 아이콘 메뉴
    - 색상, 튀어나오는 속도, 한 번 클릭으로 실행, 전체 펼치기, 버튼 표시,
      켤 때 애니메이션, 윈도우 켤 때 자동 실행, 종료


[지우는 법]
  1. 시계 옆 아이콘 우클릭 → "윈도우 켤 때 자동 실행" 체크 끄기 (켜 두었던 경우만)
  2. 같은 메뉴에서 "종료" → 원래 바탕화면 아이콘이 다시 보여요
  3. 이 폴더를 통째로 지우면 끝 (폴더 밖에는 아무것도 안 남아요)

  ※ 바탕화면 아이콘이 안 돌아오면: 바탕화면 우클릭 → 보기 → "바탕 화면 아이콘 표시" 체크


[설정 저장 위치]
  이 폴더 안의 data 폴더 (가방, 아이콘 배치, 그림). 지우면 처음 상태로 돌아가요.
  이 폴더에 쓸 수 없을 때만 %LOCALAPPDATA%\DesktopPop\data 를 대신 써요.

DesktopPop 사용법
==================

평소엔 바탕화면 아이콘을 숨겨 두었다가, 마우스를 화면 끝에 대면 아이콘이 튀어나오는 프로그램이에요.
원하는 그림으로 "가방"을 만들어 아이콘을 보관할 수도 있어요.


[켜기 / 끄기]
  켜기: 이 폴더의 DesktopPop.exe 더블클릭
    → 원래 바탕화면 아이콘이 사라지고, 시계 옆(작업 표시줄 오른쪽 아래)에 DesktopPop 아이콘이 생겨요.
  끄기: 시계 옆 아이콘 우클릭 → "종료" → 원래 바탕화면 아이콘이 다시 보여요.

  켜질 때 연출:
    화면 가운데 원형 로딩 → 빛줄기가 화면을 훑고 지나가며 원래 아이콘이 사라짐
    → 양쪽 가장자리가 잠깐 열려서 "아이콘이 여기로 왔어요"를 보여 줌.
  컴퓨터를 끄거나 다시 시작할 땐 원래 아이콘을 보이게 돌려놔요.
    → 부팅 직후엔 평소 바탕화면이 보이고, DesktopPop이 켜지면서 위 연출과 함께 숨겨져요.


[가장자리 아이콘]
  마우스를 화면 맨 왼쪽 / 맨 오른쪽 끝에 대면 아이콘이 슉 튀어나와요. 멀리 떼면 쏙 들어가요.
  처음 켤 때 원래 바탕화면에서 왼쪽에 있던 건 왼쪽, 오른쪽에 있던 건 오른쪽으로 나눠 둬요.

  - 클릭 한 번        = 선택
  - 두 번 클릭        = 실행
  - Ctrl + 클릭       = 하나씩 선택에 넣기 / 빼기
  - Shift + 클릭      = 마지막에 누른 것부터 여기까지 전부 선택
  - 빈 곳을 끌기      = 네모로 여러 개 선택 (가장자리가 열려 있을 때는 판 바로 바깥에서 시작해도 돼요)
  - 빈 곳 한 번 클릭  = 선택 풀기
  ※ 시계 옆 메뉴 "한 번 클릭으로 바로 실행"을 켜면 클릭 한 번으로 실행돼요.

  - 우클릭 = 원래 바탕화면과 같은 Windows 메뉴
      (열기, 연결 프로그램, 보내기, 압축, 잘라내기, 복사, 삭제, 이름 바꾸기, 속성 …)
      맨 위에 DesktopPop 전용: "가방에 넣기", "반대쪽 가장자리로 보내기"
      Shift + 우클릭 = 숨은 항목까지 보이는 확장 메뉴
  - 여러 개 선택하고 우클릭 = 선택한 것 전부에 적용

  - 빈 곳 우클릭 = 새 폴더 / 붙여넣기 / 바탕화면 폴더 열기

  게임·영상 전체화면이나 최대화된 창이 앞에 있을 땐 안 튀어나와요. (시계 옆 메뉴에서 바꿀 수 있어요)
  작업 표시줄(시작 버튼, 바탕화면 보기 버튼) 쪽에서는 안 튀어나와요.


[끌어서 옮기기]
  아이콘을 잡으면 마우스를 따라다니고, 원래 자리는 흐려져요. 여러 개 선택했으면 전부 같이 따라와요(개수 표시).

  놓는 곳에 따라:
  - 가장자리 판의 빈칸 / 아이콘 사이   = 그 자리로 순서 바꾸기
  - 판 안의 폴더 아이콘 한가운데       = 그 폴더 안으로 이동 (넣을 수 있으면 폴더가 테마 색으로 바뀜)
  - 판 안의 휴지통                     = 휴지통으로
  - 가방                               = 가방에 보관
  - 탐색기 창 / 다른 폴더 / 다른 프로그램 = 원래 바탕화면처럼 이동 (디스코드 등에 파일 보내기도 돼요)
  - 빈 바탕화면                        = 아무 일 없이 취소

  탐색기에서 파일을 끌어서 화면 끝으로 가져가면 가장자리가 열려요.
  판 위 원하는 자리에 놓으면 바탕화면으로 들어가요.
    같은 드라이브에서 가져오면 이동, 다른 드라이브면 복사 (Ctrl = 무조건 복사, Shift = 무조건 이동)

  바탕화면에 새로 생긴 파일 (다운로드, 새 폴더 등):
    그쪽 가장자리가 열리고 새 아이콘 자리가 반짝여요.
    바탕화면 우클릭으로 새 폴더를 만들면 마우스 위치에서 가장자리 자리로 날아가요.


[가방 (인벤토리)]
  만들기: 시계 옆 아이콘 우클릭 → "새 가방 만들기..." → 가방 그림 보관함에서 그림 고르고 이름 정하기 → 만들기

  - 가방 클릭                  = 보관한 아이콘이 주변으로 촤르륵 펼쳐짐
                                 (한 번 더 클릭 / 바깥 클릭 / Esc = 접기)
  - 가방을 꾹 누르고 끌기      = 가방 위치 옮기기
  - 아이콘을 가방 위로 끌어다 놓기 = 보관 (탐색기에서 파일을 끌어다 놓아도 돼요)
  - 펼친 아이콘을 원 밖으로 살짝 끌어 놓기 = 꺼내기
      가방 오른쪽에 놓으면 오른쪽 가장자리, 왼쪽에 놓으면 왼쪽 가장자리로 날아가 앉고 반짝여요.
  - 펼친 아이콘도 클릭·Ctrl·Shift·네모 끌기로 여러 개 선택돼요.
  - 펼친 아이콘 우클릭 = Windows 메뉴 + "가방에서 꺼내기", "다른 가방으로 옮기기"
  - 가방 우클릭 = 이름 바꾸기 / 그림 바꾸기 / 크기 / 가방 지우기
  ※ 파일을 진짜로 옮기는 게 아니라 "어디에 보여 줄지"만 기억해요. 파일은 바탕화면에 그대로 있어요.

  가방 그림 보관함 (새 가방 만들기 / 그림 바꾸기 때 열림):
  - 그림 클릭 = 고르기, 두 번 클릭 = 바로 확정 (Enter = 확정, Esc = 취소)
  - "＋ 그림 추가" = 그림 파일 고르기 (여러 장 한 번에), 그림 파일을 창에 끌어다 놓아도 추가
  - 그림에 마우스를 올리면 생기는 ✕ = 보관함에서 지우기 (이미 그 그림을 쓰는 가방은 그대로)
  - "기본 그림 다시 넣기" = 지운 기본 그림(폴더) 되살리기


[시계 옆 아이콘 메뉴]
  - 새 가방 만들기 / 바탕화면에 새 폴더 만들기 / 바탕화면 폴더 열기
  - 원래 바탕화면 아이콘 숨기기 (끄면 원래대로 보임)
  - 게임·전체화면일 땐 안 튀어나오기
  - 다른 창이 최대화돼 있을 땐 안 튀어나오기
  - 튀어나오는 반응 속도 (바로 / 보통 / 느긋하게)
  - 색상 (미리 만든 7가지 + 강조색·판 배경색 직접 고르기) — 기본은 자주·분홍
  - 한 번 클릭으로 바로 실행
  - 켤 때 시작 애니메이션 보이기
  - 윈도우 켤 때 자동 실행
  - 바탕화면 배치 다시 읽어오기 / 새로고침
  - 종료 (원래 아이콘 다시 보이기)


[지우는 법]
  1. 시계 옆 아이콘 우클릭 → "윈도우 켤 때 자동 실행" 체크 끄기 (켜 두었던 경우만)
  2. 같은 메뉴에서 "종료" → 원래 바탕화면 아이콘이 다시 보여요
  3. 이 폴더를 통째로 지우면 끝!
  ※ DesktopPop은 이 폴더 밖(내 문서, AppData 등)에는 아무것도 만들지 않아요.


[혹시 원래 아이콘이 안 돌아오면]
  작업 관리자로 강제 종료했을 때 생길 수 있어요.
  바탕화면 우클릭 → 보기 → "바탕 화면 아이콘 표시" 체크


[설정 저장 위치]
  이 폴더 안의 data 폴더
    config.json = 가방·아이콘 배치·설정
    images      = 가방들이 쓰는 그림
    library     = 가방 그림 보관함
    error.log   = 오류 기록 (문제가 생겼을 때 확인)
  → 이 폴더를 통째로 옮겨도 가방이 그대로 따라가요. data 폴더는 지우지 마세요!

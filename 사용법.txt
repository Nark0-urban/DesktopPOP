DesktopPop 사용법
==================

바탕화면 아이콘을 숨겨 두고, 마우스를 화면 왼쪽/오른쪽 끝에 대면 아이콘이 튀어나오게 해요.
선택, 실행, 우클릭 메뉴, 끌어서 옮기기는 원래 바탕화면과 똑같아요.


[원래 바탕화면과 다른 점]
  - 아이콘은 화면 왼쪽/오른쪽 끝에 마우스를 대야 보여요. 마우스를 떼면 들어가요.
    처음 켤 때 원래 왼쪽에 있던 아이콘은 왼쪽, 오른쪽에 있던 건 오른쪽으로 가요.
  - 아이콘 위치는 가장자리 판 안에서만 바꿀 수 있어요. 빈 바탕화면에 놓으면 취소돼요.
  - 끌어서 여러 개 고르는 네모는 가장자리가 열려 있을 때만 나와요.
  - 바탕화면에 파일을 넣을 때: 탐색기에서 화면 끝으로 끌고 가서 판에 놓거나,
    판의 빈 곳 우클릭 → 새 폴더 / 붙여넣기.
  - 이름 바꾸기는 입력 창에서 해요.
  - 게임·영상 전체화면이나 최대화된 창이 앞에 있으면 안 튀어나와요.
    (작업 표시줄 오른쪽 끝 "바탕화면 보기"를 누르면 열려요)


[추가된 기능]
  가방
    - 만들기: 시계 옆 DesktopPop 아이콘 우클릭 → "새 가방 만들기" → 그림 고르기
    - 아이콘을 가방에 끌어다 놓으면 보관, 가방을 클릭하면 주변으로 펼쳐져요.
    - 펼친 아이콘을 원 밖으로 살짝 끌어 놓으면 꺼내져요 (놓은 쪽 가장자리로 돌아감).
    - 가방 끌기 = 위치 이동, 가방 우클릭 = 이름 / 그림 / 크기 / 지우기
    - 파일을 실제로 옮기는 게 아니라 보여 주는 곳만 바뀌어요.

  새 파일 알림
    - 바탕화면에 새 파일이 생기면 그쪽 가장자리가 열리면서 반짝여요.

  시계 옆 아이콘 메뉴
    - 색상, 튀어나오는 속도, 한 번 클릭으로 실행, 전체화면/최대화 때 막기,
      켤 때 애니메이션, 윈도우 켤 때 자동 실행, 종료


[지우는 법]
  1. 시계 옆 아이콘 우클릭 → "윈도우 켤 때 자동 실행" 체크 끄기 (켜 두었던 경우만)
  2. 같은 메뉴에서 "종료" → 원래 바탕화면 아이콘이 다시 보여요
  3. 이 폴더를 통째로 지우면 끝 (폴더 밖에는 아무것도 안 남아요)

  ※ 바탕화면 아이콘이 안 돌아오면: 바탕화면 우클릭 → 보기 → "바탕 화면 아이콘 표시" 체크


[설정 저장 위치]
  이 폴더 안의 data 폴더 (가방, 아이콘 배치, 그림). 지우면 처음 상태로 돌아가요.
